Font template PDF

The 76-box handwriting font template is generated in your browser, which is what keeps it free and account-free — but it also means there is no file sitting on a server for you to download. If you want a PDF you can keep, email to someone, or hand to a print shop, you make it yourself in about five seconds with print-to-PDF. Here is how, plus the paper-size and printing questions that come up afterwards.

Saving it as a PDF

Open the font template and press Ctrl+P (Windows) or Cmd+P (macOS). Then:

  • Windows. In the Destination or Printer list, choose Microsoft Print to PDF — or, in Chrome and Edge, Save as PDF. Click Print and pick where to save it.
  • macOS. Use the PDF menu at the bottom-left of the print dialog and choose Save as PDF. In Chrome, the Destination list has Save as PDF directly.
  • Before you save, look at the preview. All four black corner squares must be on the page. If any are missing, set Margins to None and tick Background graphics, then check again.

That last point is the only one that really matters. Those squares are how the sheet's real size and angle are recovered from your photo — the reason print scale does not have to be exact. A sheet missing a corner marker cannot be processed, and you would find that out only after spending ten minutes writing on it.

A4, Letter, and printing somewhere else

The sheet is laid out for A4 and prints fine on US Letter. Because the corner markers carry the real size, the software solves the scale from the sheet itself instead of assuming it — so “Fit to page”, “Shrink to fit”, a slightly different paper size and a printer that quietly scales everything by 4% are all harmless. There is a wide safety border for exactly this reason.

A PDF is also the practical format if you are not printing at home. Copy shops, libraries and office printers all take a PDF on a USB stick or by email without touching the layout, which is not something you can rely on when sending a web page to print on someone else's machine.

Using it with a group

A saved PDF is the easiest way to run this with a class, a workshop or a family. Print one sheet per person — a font is built from one person's handwriting on one sheet, so they cannot be shared or combined. There is no account, no per-copy limit and no cost, so the only constraint is your paper.

Two things worth saying out loud before people start writing: use a dark pen rather than a pencil, and write normally rather than beautifully. Careful drawing produces a font that looks like careful drawing. The template page has the full list, and handwriting to font explains why each rule exists.

Questions people actually ask

How do I get the font template as a PDF?
Open the template page and print it, then choose "Save as PDF" instead of a printer — Microsoft Print to PDF on Windows, or the PDF button in the macOS print dialog. The sheet is generated in your browser rather than served as a file, so print-to-PDF is how you get a copy you can keep, email or take to a print shop.
Is the template A4 or Letter?
It is laid out for A4, but it prints correctly on US Letter too. The four black squares in the corners tell the software the sheet's real printed size, so it solves the scale rather than assuming it. Print at whatever your printer defaults to — just make sure all four squares survive onto the paper.
Do I have to print at 100% scale?
No. Scale is solved from the corner markers, so "Fit to page", "Shrink to fit" and Letter-vs-A4 differences are all fine. The only fatal setting is one that crops a corner marker off the page.
The black squares are missing from my print preview. What do I do?
Set Margins to None and tick "Background graphics" in the print dialog, then check the preview again. Without all four squares the sheet cannot be processed, and you would only discover that after writing on it — so it is worth checking before you print rather than after.
Can I print several copies for a class or a group?
Yes. The template is free with no account and no per-copy limit, so print as many as you like. Each person needs their own sheet, since a font is built from one sheet of one person's handwriting.
Can I turn the grey guide letters off before saving the PDF?
Yes, there is a toggle on the template page. The grey character shows where a letter should sit, not what it should look like — some people find it helpful and others find it tempting to trace, which produces a copy of our typeface instead of their handwriting.
Does the PDF work with other handwriting-font tools?
No, and this is worth being clear about. The corner markers and the box positions are specific to this site's processing. A template from another tool will not work here either. Use the sheet with the tool it came from.
