How to install a font

You have a .ttf file — maybe one you just made from your own handwriting — and now you need it in your apps. On a computer this takes about ten seconds. On a phone it is more involved, and in Google Docs it is not possible at all. Here is each case.

Windows

  1. 1Find the .ttf file, usually in your Downloads folder.
  2. 2Right-click it and choose Install. To make it available to everyone on the PC, choose Install for all users instead — that one needs administrator rights.
  3. 3Quit and reopen any app that was already running.

You can also drag the file into Settings → Personalisation → Fonts, which is handy for installing several at once. Microsoft's own reference is Manage fonts in Windows.

macOS

  1. 1Double-click the .ttf file. A preview window opens.
  2. 2Click Install Font. This is the step people skip — the preview alone does not install anything.
  3. 3Font Book opens and validates the font. Warnings about a missing licence or unusual metrics are normal for a home-made font and do not stop it working.
  4. 4Quit and reopen any app that was already running. On a Mac, closing the window is not enough — use Quit.

Apple's Font Book guide covers the other methods, including installing for all users.

iPhone and iPad

iOS does not install fonts from files directly. Fonts arrive through configuration profiles, so you need a font-manager app — iFont and Fontcase are the usual choices — to wrap the .ttf into a profile. The app hands the profile to Settings, you approve it there, and the font becomes available.

Two limits worth knowing before you start. Apps have to opt in to custom fonts, so the font shows up in Pages, Keynote and Numbers but not everywhere. And you cannot change the iOS system font this way — installed fonts are for use inside apps.

Android

This one depends on who made your phone. Samsung supports it directly — Settings → Display → Font size and style → Font style — though it may want the font packaged as an APK rather than a bare .ttf, which the Samsung font apps handle. Most stock Android builds have no way to add a system font without root access. Individual apps that support custom fonts are a separate matter and may still work.

Google Docs, Canva and other web apps

Google Docs cannot use your font. Its font menu is drawn from Google's own library and there is no upload, so a font installed on your computer will not appear there. If your document has to end up in Docs, the realistic options are to build the page in a desktop app and export a PDF, or to use an image of the text.

Canva does allow font uploads, under Brand settings, on its paid plans. Once uploaded the font behaves like any other in your designs.

Desktop apps just work. Word, Photoshop, Illustrator, Figma's desktop app, InDesign and Affinity all read your system fonts, so anything you install shows up — after a restart.

The font is installed but does not appear

  • The app was open during install. By far the most common cause. Quit it completely and reopen.
  • You are looking for the wrong name. Fonts are listed by the name stored inside the file, which is not necessarily the file name. If you made the font here, it is whatever you typed in the name field before downloading.
  • You previewed instead of installing. On macOS, double-clicking only opens a preview — the Install Font button still has to be clicked.
  • It went to the wrong account. A font installed for one user is not visible to another. Reinstall for all users if you need it everywhere.
  • A stale font cache. Rare, but a restart of the machine clears it and is quicker than the alternatives.

Questions people actually ask

How do I install a TTF font?
On Windows, right-click the .ttf file and choose Install. On macOS, double-click it and click Install Font. Both take a couple of seconds, and the font then appears in every app that lists your system fonts. The one step people miss is that apps only read the font list when they start, so anything already open needs restarting.
I installed the font but it is not showing up. Why?
Nine times out of ten the app was already open when you installed it. Quit it completely and reopen — on a Mac that means Quit, not just closing the window. If it still does not appear, check you are looking under the font's own name rather than the file name, and that the install actually completed rather than only previewing the font.
Can I install a font on an iPhone or iPad?
Yes, but not by tapping the file. iOS installs fonts through configuration profiles, so you need an app such as iFont or Fontcase to wrap the .ttf into a profile, which you then approve in Settings. Once installed the font is available in Pages, Keynote, Numbers and other apps that support custom fonts — though not in every app, and not in the system interface.
How do I use a custom font in Google Docs?
You cannot install one directly. Google Docs only offers fonts from Google's own library, and there is no upload. The practical routes are to use the font in a desktop app such as Word and export a PDF, or to use it in Canva, which does allow font uploads on its paid plans.
Can I install a font on Android?
It depends on the phone. Samsung devices can install fonts through Settings under Display, and some other manufacturers have similar options. Most stock Android builds cannot change the system font without root access, though individual apps that support custom fonts may still let you use it.
Do I need to keep the .ttf file after installing?
No. Both Windows and macOS copy the font into the system when you install it, so the original file can be moved or deleted. Keep a backup anyway — if you made the font yourself, that file is the only copy.
Can I use a font I made on a font I share with other people?
A font you made from your own handwriting is yours to use and to share. But remember that anyone you send the .ttf to has to install it too — if you send them a document instead, embed the font or export a PDF, otherwise their computer will substitute something else.
